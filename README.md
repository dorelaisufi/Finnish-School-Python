# Finnish School Python

## What is Python?

Python is a **programming language** that is easy to learn. We use it to write instructions for computers and robots.

## Why Do We Use Python for mBot2?

We use *Python* to control mBot2. We can write commands to display text, change LED colours and control the robot.

## What is a Python Comment?

A comment is a note in the code that explains something. Python ignores comments. We use the # symbol.

## Why Do We Display Text?

Displaying text helps us show information, messages and results on a screen.

## Three Python Examples

1. Display a message:
```python
print("Hello World")
```

2. Create a variable:
```python
name = "Dorela"
print(name)
```

3. Write a comment:
```python
# This is my ICT project
print("Python is fun")
```
